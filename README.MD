# Лабораторная работа 3 - Конфигурационное управление (Ansible)

   ## Часть 1: Использование Ansible для установки NGINX

   ### Структура проекта
   - `hosts` - файл инвентаризации
   - `play.yml` - главный плейбук
   - `roles/nginx/` - роль для установки и настройки NGINX

   ### Команда применения роли
   ansible-playbook -i hosts play.yml -K

   ### Проверка результата
   Открыть в браузере: http://localhost
